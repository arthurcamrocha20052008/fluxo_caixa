# Frontend

Esta pasta é o ponto de entrada para a aplicação web do Fluxo de Caixa. A aplicação ainda não foi implementada.

Mantenha aqui o código-fonte, os arquivos de configuração, as dependências e os testes próprios do frontend. A API está disponível em `http://fluxocaixa:8000`; a origem local autorizada pelo CORS é `http://fluxocaixa`.

Para abrir o frontend sem número de porta, o servidor de desenvolvimento ou proxy local deverá atender em HTTP na porta 80. Escolha o framework e o comando de inicialização ao começar a implementação.
